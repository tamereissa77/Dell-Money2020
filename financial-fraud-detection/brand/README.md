# Brand assets

Drop the **official** logo files here. Nothing in this repo redraws or approximates
either company's mark — until these files exist, the UI and deck fall back to plain
typographic wordmarks, which is the safe behaviour for a public event.

## Expected filenames

| File | Use | Source |
|---|---|---|
| `dell-technologies-white.png` (or `.svg`) | UI header, deck (dark backgrounds) | Dell Brand Central |
| `dell-technologies-blue.png` | deck (light backgrounds), print | Dell Brand Central |
| `nvidia-white.png` (or `.svg`) | UI header, deck (dark backgrounds) | NVIDIA Brand Portal |
| `nvidia-green.png` | deck (light backgrounds) | NVIDIA Brand Portal |

Recommended: PNG with transparency, at least 600 px wide, or SVG.
The UI auto-detects whichever files are present and hides the slot if none are.

## Co-branding notes

- Both companies' guidelines require **clear space** around the mark — the layout
  reserves it; do not tighten it.
- Do not recolour, stretch, rotate or add effects to either mark.
- Partner lockups are normally separated by a thin vertical rule with equal optical
  weight on both sides. That is how the UI header and deck title are built.
- Confirm the specific lockup with Dell brand/marketing before a public event.
  This repo positions the assets; it cannot approve their use.
